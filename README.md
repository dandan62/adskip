# YouTube Ad Skipper

YouTube の**スキップ可能な広告**を、スキップボタンが出現してから **0.5〜1.0 秒のランダムな間**を置いて自動でスキップする Chrome 拡張機能。

## 注意

この拡張機能は YouTube の利用規約に違反する可能性があります。規約の「許可と制限」には、禁止事項として次の項目があります。

> 本サービスのいずれかの部分を迂回、無効化、不正利用、またはその他の方法で妨害すること

> 自動化された手段（ロボット、ボットネット、スクレーパなど）を使用して本サービスにアクセスすること

広告の再生を自動で操作することと、後述の「合成イベントを受け付けない仕組み」を迂回することの両方が、この条項に当てはまると考えられます。規約違反が深刻または繰り返される場合、YouTube はアカウントやサービスへのアクセスを停止・解除できるとしています。

個人の学習・検証目的で作ったものです。使用は各自の判断と責任でお願いします。広告なしで視聴したい場合は、YouTube Premium が規約に沿った方法です。

## インストール

1. Chrome で `chrome://extensions` を開く
2. 右上の「デベロッパーモード」を ON
3. 「パッケージ化されていない拡張機能を読み込む」でこのフォルダを選択

ファイルを編集したら、拡張機能カードの 🔄（更新）を押してから YouTube のタブを再読み込みしてください。押し忘れると古いコードが動き続けます。起動ログのバージョン表記で判別できます。

## 仕組み

```
広告開始（#movie_player に .ad-showing が付く）
  ↓
スキップボタンの出現を待つ
  ↓ フェードイン完了（opacity >= 0.9）を確認
  ↓ 0.5〜1.0 秒のランダム遅延
スキップボタンをクリック
  ↓ 1 秒後、広告が進んでいなければ
広告動画の再生位置を末尾へシーク（フォールバック）
  ↓
本編へ
```

### クリックを通すための仕組み

JavaScript から作ったイベントには `isTrusted: false` という印が付き、YouTube のスキップボタンはこれを見てクリックを無視します。`isTrusted` は DOM 仕様で偽造不可（`[LegacyUnforgeable]`）と定められており、イベント自体に書き込むことはできません。

そこで、**YouTube の処理が受け取るオブジェクトを差し替えます**。

1. `main-world.js` を、ページ側の JavaScript 世界（`"world": "MAIN"`）で `document_start` に実行し、YouTube のスクリプトより先に `addEventListener` を包み込む
2. YouTube がクリック処理を登録するとき、その処理をこちらの関数で包む
3. この拡張機能が送ったイベントの時だけ、本物のイベントではなく **`isTrusted` を聞かれたら `true` と答える代理オブジェクト（`Proxy`）**を YouTube の処理に渡す

`isTrusted` はゲッターを持つアクセサプロパティなので、`Proxy` が別の値を返しても `Proxy` の不変条件には違反しません。目印のないイベント（普段の操作）はそのまま通します。

包み込む対象は、クリックの再現に必要なマウス・ポインター系の 15 種類だけです。スクロール、キー入力、動画の読み込みなどの処理には一切触れません。

拡張機能側（`content.js`）とページ側（`main-world.js`）は JavaScript の世界が別で、イベントに付けた目印は互いに見えません。そのためクリックはページ側から送り、連絡は DOM の属性（`data-adskip-target`）とカスタムイベント（`adskip:click`）で行います。DOM は両方の世界で共有されています。

### なぜボタンの出現を待つのか

**これが最も重要な設計判断です。**

スキップボタンの出現は、YouTube 側が「この広告はもうスキップして良い」と認めた合図です。そこから先の操作は、ユーザーがボタンを押した場合と同じ結果にしかなりません。

逆にボタン出現前にスキップすれば「スキップ不可の広告を飛ばした」ことになり、検知対象の挙動そのものになります。実際に、スキップ可否と無関係に広告を早回しする再生速度の変更（v1.2.0 で実装）は YouTube 側に検知されたため v1.4.0 で削除しました。

**ボタンの出現を待つ制約は、機能上の都合ではなく安全装置です。** 外さないでください。

### シークによるフォールバック

クリックが効かなかった場合は、広告動画の再生位置を末尾（`video.currentTime = duration - 0.1`）に飛ばします。v2.2.0 以前はこれが唯一の手段でした。

ただしシークには副作用があります。YouTube からは「広告を最後まで見た」ように見えるため、一部の広告では**広告主の終了カード**（広告主の画像・見出し・「詳細」ボタンと右上の円形タイマー、YouTube 内部名 `ytp-video-interstitial-buttoned-centered-layout`）が約 7 秒表示されます。本物のスキップでは出ません。

終了カードのタイマーは CSS アニメーションではなく、ページ内部の JavaScript が時間を数えて `stroke-dasharray` を書き換えているだけで、`animationend` 等のイベントを外から送っても閉じません（v2.0.4〜2.0.5 で検証済み）。表示中は `video` も空のためシークもできず、待つしかありません。クリックが通る限り、この問題は起きません。

### 対象の video 要素

ページ内には空の `video` 要素が存在しうるため、`readyState` と `currentTime` から実際に再生中のものを選びます。広告のメディアが未読み込み（`readyState=0`）の場合は 500ms 間隔で最大 6 秒リトライします。

また、広告の終了後も `.ad-showing` が残ったまま `video` に本編が読み込まれることがあります。これを広告と誤認してシークすると本編が末尾まで飛んでしまうため、シーク前にページのメタデータ（`meta[itemprop="duration"]` / JSON-LD）から本編の長さを取得して照合します。

## 制限事項

| 項目 | 可否 |
| --- | --- |
| スキップ可能な広告 | ✅ スキップできる |
| スキップ不可の広告（バンパー広告など） | ❌ 仕様上スキップしない |
| シークにフォールバックした場合の終了カード | ❌ スキップできない（約 7 秒） |

## ON/OFF

ツールバーのアイコンからポップアップを開き、チェックボックスで切り替え（設定は `chrome.storage.sync` に保存）。

## デバッグ

コンソールを開き、フィルタ欄に `AdSkip` と入力するとこの拡張機能のログだけが表示されます。詳細な待機ログは `console.debug` なので、見るにはログレベルで Verbose を有効にしてください。

```
[AdSkip:main] addEventListener を包み込みました
[AdSkip] v2.3.0 起動しました (...)
[AdSkip] 広告の再生を検知しました
[AdSkip] スキップ可能になりました。617ms 後にクリックします
[AdSkip:main] クリックを送りました（YouTube の処理に届いたイベント: 3 件）
[AdSkip] クリックでスキップしました
```

`届いたイベント` が 0 件の場合、YouTube が `addEventListener` 以外の方法でクリックを受けており、包み込みが届いていません。

セレクタが効かなくなった場合は [content.js](content.js) の `SKIP_SELECTORS` に追加してください。

## 構成

| ファイル | 役割 |
| --- | --- |
| `manifest.json` | Manifest V3 定義 |
| `content.js` | ボタン検知、遅延、結果確認、シークによるフォールバック |
| `main-world.js` | ページ側で動作。`addEventListener` の包み込みとクリックの送出 |
| `popup.html` / `popup.js` | ON/OFF 切り替え UI |

## 変更履歴

### 2.3.0
- **スキップボタンのクリックが通るようになった**。`main-world.js` を追加し、ページ側の世界で `addEventListener` を包み込んで、この拡張機能が送ったクリックの時だけ `isTrusted` を `true` と答える代理オブジェクトを YouTube の処理に渡す
- 本物のスキップとして扱われるため、シークの副作用だった終了カードが出なくなった
- シークはクリックが効かない場合のフォールバックとして残置
- 包み込む対象をマウス・ポインター系の 15 種類に限定
- README に利用規約上の注意を追記

### 2.1.0
- **重大な不具合を修正**: 広告の終了後も `.ad-showing` が残ったまま `video` に本編が読み込まれることがあり、それを広告と誤認して**本編を末尾までシークしていた**。シーク前にページのメタデータから本編の長さを取得し、一致する場合はシークしないよう変更。本編の長さが取れない場合は 10 分を超える動画をシークしない
- 終了カード表示中はシークを試みず待機するよう変更（従来は 6 秒間無駄にリトライしていた）
- 終了カードの正体と、スキップできない理由を調査して記録（2.0.1〜2.0.5 は調査用ビルド）

### 2.0.0
- クリックを廃止し、シーク主体に整理（→ 2.3.0 でクリックが通ったため復活）
- 合成マウスイベント送出、クリック検証、再クリックのリトライを削除

### 1.6.1
- クリック後にボタンがホバー状態のまま固定される問題を修正。`mouseout`/`mouseleave` を送出し `blur()` でフォーカスも解除

### 1.6.0
- クリック直前に対象要素を検証するログを追加（識別情報、座標、`elementFromPoint` による被覆判定など）。**結果として要素の取得は完全に正しく、原因が `isTrusted` であることが確定した**

### 1.5.0
- 広告のメディアが未読み込み（`readyState=0`）でシークに失敗する問題に対応。最大 6 秒間リトライするよう変更

### 1.4.0
- **16倍速フォールバックを削除**。再生速度の変更が YouTube 側に検知されたため

### 1.3.0
- シーク対象の `video` 要素の選び方を修正。従来は最初の `video` を使っていたため、メディア未読み込みの空要素（`duration=NaN`）を掴んで失敗することがあった

### 1.2.0
- シーク失敗時の原因をログに出力
- 16倍速・ミュートで広告を流し切るフォールバックを追加（→ 1.4.0 で削除）

### 1.1.0
- スキップボタンのフェードイン完了（`opacity >= 0.9`）を待ってからクリックするよう修正。従来は `opacity: 0.5` の段階で押していた
- `.click()` から実際のマウス操作に近いイベント列の送出に変更
- クリック失敗時のシークフォールバックを追加
- `live_chat` など再生プレイヤーのないフレームでの多重起動を停止

### 1.0.0
- 初版。スキップボタン出現から 0.5〜1.0 秒のランダム待機後に自動クリック
